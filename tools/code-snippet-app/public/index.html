Code Snippet Tool

Three inputs. One button. Paste-ready HTML + CSS + JS for a homepage section. The POC pastes and publishes; this page only writes code.

Input

a
Say what it must achieve, not just what it contains. Colours, copy or images you leave out become clear placeholders like [SELLER NAME].
b

Paste a screenshot with Ctrl/⌘+V, drop a file here, or:

or

Claude sees the images directly, and reads each link's title, headings, text, colours and fonts. All of it is visual reference only: it never copies another site's markup, brand or assets.
c
The row name on Website → Home. ALL-CAPS matches the storefront section title. The CSS prefix is derived from it automatically.
